## 二、尚未验证（需要解锁手机）

- **App 界面交互**：设备带 4 位 PIN 锁屏，`adb` 无法注入解锁（Android 17 限制 INJECT_EVENTS），UI 只能编译期验证 + 静态检查。
- **App → su 授权弹窗**：首次运行会弹 KernelSU 授权框，需要在解锁状态下点「允许」。

解锁后按下面步骤即可完成最后验证：

```bash
adb install -r dist/MihomoTProxy-1.0.0.apk
# 手机上：打开 App → KernelSU 弹窗点「允许」
adb logcat -s MihomoTProxy:* | findstr /i "install error"
adb shell su -c "ls -l /data/adb/mihomo_tproxy/bin /data/adb/mihomo_tproxy/data"
```

## 三、复现命令（核心链路）

```bash
# 1. 安装配置并启动
adb push config.yaml /data/local/tmp/config.yaml
adb shell su -c "cp /data/local/tmp/config.yaml /data/adb/mihomo_tproxy/data/config.yaml"
adb shell su -c "sh /data/adb/mihomo_tproxy/ctl.sh start"

# 2. 校验
adb shell "curl -s -H 'Authorization: Bearer <secret>' http://127.0.0.1:9090/version"
adb shell "curl -s -m 8 -o /dev/null -w '%{http_code}' https://www.baidu.com"
adb shell su -c "ip link show mihomo0; ip rule show | head -4"

# 3. 热重载 / 模式切换
adb push reload.json /data/local/tmp/reload.json     # {"path":"/data/adb/mihomo_tproxy/data/config.yaml"}
adb shell "curl -X PUT -H 'Authorization: Bearer <secret>' -H 'Content-Type: application/json' --data-binary @/data/local/tmp/reload.json 'http://127.0.0.1:9090/configs?force=true'"
adb push direct.json /data/local/tmp/direct.json     # {"mode":"direct"}
adb shell "curl -X PATCH -H 'Authorization: Bearer <secret>' -H 'Content-Type: application/json' --data-binary @/data/local/tmp/direct.json http://127.0.0.1:9090/configs"

# 4. 停止并确认清理
adb shell su -c "sh /data/adb/mihomo_tproxy/ctl.sh stop"
adb shell su -c "ip link show mihomo0; ip rule show | head -4"
```

## 四、已知注意点

1. mihomo 只允许热重载 `-d` 目录内的配置，所以运行配置放在 `/data/adb/mihomo_tproxy/data/config.yaml`（与 `-d` 同目录）。
2. 配置中同名节点会让 mihomo 直接 `fatal`，因此整合/链接导入路径做了去重与改名；外部订阅若自带重名节点，请用「整合全部节点」重新生成。
3. 测试节点的 UDP 走不通会导致 `client hanshake error: EOF` 刷日志，这是节点不支持 UDP，不是链路问题。
